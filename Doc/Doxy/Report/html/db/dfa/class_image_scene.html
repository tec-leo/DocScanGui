Class : ImageScene.h

Description :

◆ makeRect()

void ImageScene::makeRect ( QRectF rect)

This function creates a rectangle with 4 points (circles) at each edge of the rectangle. The points are selectable and moveable, the index of the points is stored in the custom data of the circles (QGraphicsItem).

Note the order of the points top left, right and bottom left, right. BottomRight should be the last for stretch a rectangle.
