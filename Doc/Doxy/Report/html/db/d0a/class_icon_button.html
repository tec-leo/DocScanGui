◆ hitButton()

bool IconButton::hitButton ( const QPoint & pos) const
protected

This function returns true if the given point position is inside the clickable button rectangle; otherwise returns false. The clickable area is the entire widget. An additional check is done if the point is within the icon, in this case the signal 'iconToggled' is sent with the index of this button.
