Detailed Description

Class : ImageView.h

Description :

This class is derived from 'QGraphicsView' and implements a 'QGraphicsView' which is is derived from QAbstractScrollArea and can be used as widget for example in a QTabWidget. It creates a new graphic scene and sets it as current 'scene'.
