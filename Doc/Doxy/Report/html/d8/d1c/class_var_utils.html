◆ seedRandom()

void VarUtils::seedRandom ( qint32 seed = -1)
static

This function creates a new 32 bit random generator with the given seed. If the seed is -1 then it is intialized with the global object that was securely seeded with QRandomGenerator::system. This is the recommended way for creating a new QRandomGenerator object that will be kept for some time.

Note : for compatibility with the stl use the QRandomGenerator64

seednew seed for the random generator
