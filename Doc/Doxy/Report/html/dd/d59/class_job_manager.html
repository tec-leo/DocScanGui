◆ loadConfig()

void JobManager::loadConfig ( )
protected

This function is called from 'evalCmdLine' and loads and parses a config file for options. This config file contains command line options in ini format, this means it contains key / entry pairs like useGui=true. The arguments from the command line have priority over options in the config file.

The config file can be set on the command line with name args_file, like this: –arg_file=D:/DocScanGui/Scan/DocGray-1.cfg

◆ loadJobFiles()

void JobManager::loadJobFiles ( )
protected

This function loads and parses the job file for options. It checks if there are references to other job files which should be loaded.

The entry 'JobFiles' contains just numbers of job files, the file names are stored in seperate entries, the path can be absolute or relative. If the name contains no path then they are found when they are in the same directoy as the main job file.

Example:

[Jobs] JobCount=1,2-6 JobFiles=2,3,5 JobFile-1=RunJob-1.txt JobFile-2=RunJob-2.txt JobFile-3=RunJob-3.txt JobFile-4=RunJob-4.txt JobFile-5=RunJob-5.txt

Here the job files 2, 3 and 5 are loaded and executed after the the jobs 1 and 2-6 are executed and finished.
