◆ runMorphTrans()

void ToolsWidget::runMorphTrans ( )
protected

This function executes some morphological transformations like dilate or closing to improve the shape of text. This can be used if the text is rather 'thin' on the scanned document.

Before it calls 'getStructuringElement' which returns a structuring element of the specified size and shape for morphological operations. This element can be further passed to erode, dilate or morphologyEx. But you can also construct an arbitrary binary mask yourself and use it as the structuring element.

Parameters for getStructuringElement shape Element shape that could be one of MorphShapes ksize Size of the structuring element. anchor Anchor position within the element. The default value means that the anchor is at the center. Only the shape of a cross-shaped element depends on the anchor position.

The definition are in types_c.h and in interface.h.

Definitions for the morphological operations tpye:

MORPH_ERODE 0, MORPH_DILATE 1, MORPH_OPEN 2, MORPH_CLOSE 3, MORPH_GRADIENT 4, MORPH_TOPHAT 5, MORPH_BLACKHAT 6
