Detailed Description

Class : ButtonsWidget.h

Description :

This class implements a widget with a list of IconButtons. Every button has a name and a state which can be toggled between on and off. The state is visible with different icons for (power) on and off.

◆ onBtnClicked

void ButtonsWidget::onBtnClicked ( bool checked)
protectedslot

This function is called when a button in the widget is pressed. It is checked if the sender is a QPushButton and if so a signal sent out which informs about the index and 'checked' state of this button.

It is not necessary to block signals when calling setChecked, because it does not signal 'clicked', but 'toggled'.

Parameters
checkedChecked state of the selected button
