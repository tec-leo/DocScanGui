Detailed Description

Class : LayersList.h

Description :

This class implements a widget with a list of IconButtons. Every button represents a layer in the graphic scene and has a name and a visibility state. The state can be toggled to indicate that the layer is visible or hidden. The visibility is shown with different icons for (power) on and off.

void LayersList::onIconToggled ( int index)
protectedslot

This function is called when a button in the widget is pressed. It is checked if the sender is a QPushButton. It toggles the 'active' property of this button and changes the icon depending on the 'active' state. Index and 'active' state are then sent by the signal 'btnIconToggled'.
