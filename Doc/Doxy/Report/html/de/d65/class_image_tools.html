◆ addMargins()

Mat ImageTools::addMargins ( Mat input)

This function adds page margins to the given image with white color. The page margins are interpreted as percentage of the input image size not pixels. The margins order is top, bottom, left, right.

The page padding is done with 'copyMakeBorder', the border type is set to isolated, which means that the extrapolation for the padding is using only pixels inside the input image (no ROI - region of interest).

Parameters
inputInput image
Returns
Mat Image with margins

Mat ImageTools::deskewAndCrop ( Mat input,
const RotatedRect & box )

This function rotates the image by the angle of the rotated rect and makes a border around the rotated box.

For this it calls 'copyMakeBorder' which copies the source image into the middle of the destination image. The areas to the left, to the right, above and below the copied source image will be filled with extrapolated pixels.

◆ findRegions()

void ImageTools::findRegions ( Mat input,
L_RotatedRect & areas )

This function uses 'findContours' to detect the connected pixels regions (extremal regions). For each contour (region) it uses 'minAreaRect' to find the rotated rectangle (possibly rotated) for a identified point set. The returned RotatedRect can contain negative indices when data is close to the containing Mat element boundary.

Small regions with width or height below a minimum value like 20 are ignored, also a width / height ratio below a minimum value like 2.

Parameters
inputMatrix to evaluate for regions
areasReference to a list with all rotated rectangles

◆ getMarginsBox()

cv::Rect ImageTools::getMarginsBox ( Mat input)

This function checks if at the margins of the given image are some distortions or artefacts from a wrong scan frame. The image must already be binarized with 8 bit and inverted, this means white text (content) on black. Then is reduces the margins of the image ( but only to 10 % ) untils no artefacts at the margins can be found. If it has no success the full image size is returned in the rect.

◆ rotateImage() [2/2]

Mat ImageTools::rotateImage ( Mat input,
float & angle )
protected

This function rotates the image by simplifying the angle to a range between +/- 45 degrees. For this it first evaluates the quadrant and does a rotation of multiples of 90 degrees.

A final angle between +/- 45 degrees allows an easier padding and cropping of image. The given angle assumes that positive values mean a clockwise rotation.

Parameters
inputInput image for rotating
angleReference to the input and remaining angle
Returns
