void ColorCurves::applyCurve ( cv::Mat & matIn,
cv::Mat & matOut )

This function is called from the tools widget when some curves or black or white points has changed in the curves dialog. Then a lookup table is calulated from the curves and applied to the given image mat and stored in the output image mat.

When a applyColors is set then the colors channels are individually calculated and merged, this is only the case when 'Auto level' is executed.

◆ getLuminosity()

float ColorCurves::getLuminosity ( cv::Vec3b color)

This function calculates the luminosity value from the given 3 channel color and returns it. The color is in uchar format, therefore it its converted to floating point value in the range between 0 and 1. For the calculation of the luminosity the OpenCV formula is used. The given color is in RGB format.

There are 2 different formula for the conversion from color to gray:

OpenCV luminosity formula: Y = 0.299 R + 0.587 G + 0.114 B

Gimp luminosity formula: Y = 0.222 R + 0.717 G + 0.061 B

Parameters
colorVector for 3 colors in uchar format
Returns
float Gray value as floating point
