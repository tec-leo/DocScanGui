◆ sharpGaussian()

Mat Filters::sharpGaussian ( Mat input,
double alpha,
double beta,
double gamma )

This function sharpens the given image by first bluring it and then subracting the blured image with a certain multiplication factors. For this it calls addWeighted with the following parameters:

InputArray src1 --> first input array double alpha --> weight of the first array elements InputArray src2 --> second input array (same size and channels) double beta --> weight of the second array elements double gamma --> scalar added to each sum OutputArray dst --> output array int dtype --> -1 means the same depth as source image

The function addWeighted calculates the weighted sum of two arrays:

dst (I) O = saturate ( src1 (I) * alpha + src2 (i) * beta + gamma )

Default values: alpha = 1.5 beta = - 0.5 gamma = 0.0

Default values: Gaussian - kernel size = 3 Gaussian - sigma = 0 Laplacian - kernel size = 3

This function sharpens the given image by applying an 'unsharp' mask. The typical blending formula for unsharp masking is : sharpened = original + (original - blurred) x amount

Default values: Gaussian - kernel size = 0 Gaussian - sigma = 1.0 brightness - threshold = 5 contrast added - amount = 1
