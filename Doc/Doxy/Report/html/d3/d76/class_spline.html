◆ setPoints()

bool Spline::setPoints ( QPolygonF points)

This function stores the given points and calculates the spline coefficients depending on the spline type. This function will determine the coefficients for a natural or a periodic spline and store them internally. The sequence of the x-coordinate of the points has to be strictly monotone increasing, or the function returns with false.

Note: only natural is implemented

Parameters
pointsPoints
Returns
bool true - x points are strictly monotone increasing,
