Class : ImageMat.h

Description :

This class implements some helper functions evaluating an image and several conversion functions like get a QImage from a 'Mat' from OpenCV.

Mat ImageMat::binarize ( Mat input,
int threshold = -1 )

This function converts the image first to gray scale and then applies 'threshold' to the simple threshold function of OpenCV. If the given threshold is below 0 the it uses the 'otsu' algorithm (automatic threshold finding) to make it binary.

◆ getBlackRatio()

double ImageMat::getBlackRatio ( Mat & mat)

This function counts the pixel which are closer to black by a defined threshold value. It assumes that the given matrix is a gray image (one channel) with unsigned 8 bit values and white on black text.

It calculates the ratio of black text to all pixel on a document. Black text means a value of 0 for the black pixels.

Parameters
matInput matrix
Returns
double ratio of black text to all pixels in a text doc
